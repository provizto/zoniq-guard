Integrate automated security gates directly into deployment pipelines via the official repository (provizto/zoniq-guard). Every pull request is statically analyzed; any commit introducing Critical or High vulnerabilities is automatically blocked from merging into production.

Native GitHub Actions Integration

.github/workflows/zoniq-guard.yml Pre-Merge Protection 
name: Zoniq Guard Security Gate
on: [push, pull_request]
jobs:
  contract-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run Zoniq Guard Analyzer
        uses: zoniq/guard-action@v2
        with:
          fail-on-severity: 'CRITICAL,HIGH'
